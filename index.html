Detailed Settings Guide

Comprehensive configuration options for optimal gaming experience

Performance Settings

UnCap (FPS Unlocker) +
Function: Unlock the frame rate limit to achieve smoother gameplay

Options: 9999 FPS maximum
Effect: Removes 60 FPS cap
Recommended: For high refresh rate monitors (144Hz, 240Hz, etc.)
Graphics Optimization Mode +
Function: Determine the engine strategy for rendering graphics

Options: Performance, Balanced, Quality
Performance: Maximum FPS, lower visual quality
Quality: Best visuals, lower FPS
Balanced: Optimal mix of both performance and quality
Rendering Mode +
Function: Select graphics API for rendering

Options: DirectX11, Vulkan
DirectX11: Best compatibility (recommended for most users)
Vulkan: Better performance on supported systems (AMD/Modern NVIDIA)
Render Resolution Cap +
Function: Sets the maximum total render pixel limit

Options: 144p, 240p, 360p, 480p, 720p, 1080p, 1440p, 4K
Lower resolutions: Better performance, lower visual clarity
Higher resolutions: Better visual clarity, requires more GPU power

Visual Settings

Reduced Motion +
Function: Reduce certain animations and motion effects in the game

Options: true, false
true: Minimal animations, better performance
false: Full visual effects (more immersive)
Player Name Display +
Function: Control display of player names in-game

Options: true, false
true: Show all player names
false: Hide player names (improves visibility in crowded games)
Anti Aliasing Quality (MSAA) +
Function: Smooth the edges of 3D objects for better visual quality

Options: 0 (Off), 1 (Low), 2 (Medium), 4 (High), 8 (Ultra)
Higher values: Smoother edges, more GPU usage
Lower values: Better performance, sharper edges
Texture Quality +
Function: Lock Roblox texture quality at a certain level

Options: 0-10 (0 = Lowest, 10 = Highest)
0: Lowest quality, best performance
10: Highest quality, most GPU usage
Recommended: 3-5 for balanced experience

Technical Support

Settings not applying properly +
Troubleshooting steps:

1. Ensure Roblox is completely closed when applying FFlags
2. Run Impaction as administrator
3. Verify Roblox installation path in settings
4. Download a fresh copy from the official website

Most issues are resolved by ensuring Roblox is not running during configuration.
Game crashes or performance issues +
Quick fixes:

1. Use Performance mode in Graphics Optimization
2. Change Rendering Mode to DirectX11
3. Lower Render Resolution (try 720p)
4. Disable Anti Aliasing (set to 0)
5. Close other applications while gaming
6. Ensure your graphics drivers are updated

Start with minimal settings and gradually increase until you find optimal balance.
FPS still capped at 60 +
Solutions:

1. Verify UnCap is set to "9999"
2. Ensure you're using the latest version of Impaction from official site
3. Check if your monitor refresh rate is properly set in Windows
4. Try different Rendering Mode (Vulkan sometimes works better)
5. Disable VSync in Roblox settings if enabled

The FPS unlock works by modifying Roblox's internal frame limiter settings.
Visual glitches or artifacts +
Common solutions:

1. Switch Rendering Mode between DirectX11 and Vulkan
2. Reset to default settings in Impaction
3. Lower Texture Quality setting
4. Disable Anti Aliasing temporarily
5. Update your graphics card drivers
6. Ensure Roblox is updated to latest version

Some games may have compatibility issues with certain FFlag combinations.
